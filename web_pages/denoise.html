02Remote denoise workers
03How it works
Each bus runs its own DP8 stream (DPDFNet at 8 kHz). Local runs it on this box. Remote streams the bus to a denoise worker in 50 ms chunks, and the result is the same, bit for bit. If the worker's reply is late, or there's no worker at all, that chunk plays dry (not denoised). It never falls back to local, because that would put the load back on this box. Workers register themselves (tools/denoise_worker.py), so no address goes in config. Settings save to routing_config.json, the same file the D button and mix slider in Routing use.
