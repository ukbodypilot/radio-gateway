# Python dependencies for radio-gateway.
#
# For most users, use scripts/install.sh — it handles system packages
# (PortAudio, HIDAPI, FFmpeg, ALSA loopback, UDEV rules, etc.) and the
# Python set below. This file is kept for users who want to manage the
# Python layer separately or verify the import list against their env.
#
#     pip install -r requirements.txt
#
# IMPORTANT: install.sh does NOT read this file. It installs each package
# explicitly, because several need handling a flat `pip install -r` gets
# wrong (see the --no-deps and pymumble notes below, and the protobuf
# re-pin). That means these two lists are maintained by hand and can drift —
# which has bitten twice, both times as a package the code imports being
# absent from the installer while the failure stayed invisible:
# faster-whisper (every whisper/* model failed to load) and
# prometheus-client (instrumentation silently no-opped, /metrics 500'd).
#
# After editing EITHER file, run:
#
#     python3 tools/check_deps_drift.py
#
# It diffs the two lists and exits non-zero on drift; install.sh's health
# check runs it too. Deliberate differences live in that script's EXPECTED_*
# sets, each with a justification.
#
# Notes on a few packages:
#   * pymumble — the PyPI name varies. Try pymumble-py3 first; if that
#     fails, plain `pymumble` works too. The gateway imports via a
#     fallback chain (see gateway_core.py).
#   * silero-vad and pyrnnoise — install.sh uses `pip install --no-deps`
#     to skip torch and matplotlib respectively. If you're installing
#     directly from this file, expect the full dep tree to pull in.
#   * kv4p-ht-python — external git repo, not on PyPI. install.sh clones
#     it to ~/kv4p-ht-python and pip installs editable. You can do the
#     same manually:
#         git clone https://github.com/ukbodypilot/kv4p-ht-python.git ~/kv4p-ht-python
#         pip install -e ~/kv4p-ht-python

# ── Audio I/O ────────────────────────────────────────────────
numpy
scipy
pyaudio
soundfile
resampy
sounddevice

# ── Serial / HID ─────────────────────────────────────────────
pyserial
hid

# ── Codecs ───────────────────────────────────────────────────
opuslib

# ── Mumble client (PyPI name varies) ─────────────────────────
pymumble-py3>=1.0.0 ; python_version >= "3.8"

# ── Text-to-speech ───────────────────────────────────────────
# kokoro-onnx is the default engine (offline, high quality, 54 voices).
# ONNX model files (~340 MB) are downloaded separately by install.sh into
# tools/models/kokoro/ and are not stored in git.
kokoro-onnx
gtts
edge-tts

# ── System metrics ───────────────────────────────────────────
psutil
prometheus-client

# ── MCP server (Claude AI control) ───────────────────────────
mcp<2                   # mcp_server uses mcp.server.fastmcp, which 2.x removed

# ── Speech transcription (Moonshine + Whisper + Silero VAD) ──
# Moonshine runs on onnxruntime (no torch); Silero VAD ships a bundled
# ONNX model and uses onnxruntime directly.
# BOTH engines are supported and both are selectable on /transcribe:
# useful-moonshine-onnx backs the moonshine/* model keys (the default) and
# faster-whisper backs the whisper/* keys. Install both, or picking a
# whisper/* model in the UI fails at load time.
useful-moonshine-onnx
faster-whisper
silero-vad
onnxruntime

# ── Neural denoise (DFN / RNNoise) ───────────────────────────
# pyrnnoise bundles librnnoise.so; we bind via ctypes and skip the
# package __init__ so audiolab/matplotlib are not required.
pyrnnoise

# ── Windows audio client (windows_audio_client.py only) ──────
# No extra packages needed beyond numpy + scipy (already required above):
# keys are read from the console input buffer (focus-local, no global hook),
# and the voice effects (n/m) are in-process DSP. A few effects (telephone/
# megaphone/underwater) use scipy filters and degrade to clean mic if absent.
